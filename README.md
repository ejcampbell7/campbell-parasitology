# Campbell Parasitology Lab & FR3 — website

Source for the lab website and FR3 (Filariasis Research Reagent Resource
Center) site, built with Jekyll for GitHub Pages.

**Start here → [SETUP.md](SETUP.md)** for step-by-step instructions to
publish this site and add content later (news posts, publications, team
members) — no coding experience required.

## Structure

```
_config.yml         Site title, nav, contact info — the main settings file
index.md            Homepage
research.md         Research overview
people.md           Team listing page
_people/            One file per team member
publications.md     Publications listing page
_publications/       One file per publication
fr3/                FR3 overview, resource-request info, SOPs
news.md             News listing page
_posts/             One file per news post
_layouts/, _includes/, assets/css/  Design/templates — edit with care
```
